Portal Seeker AI

CODE 111

An AI villager with two boot documents and no map. It hears a hum, follows the warmth, and reaches an end it was never told about.

Doesn't know. Tries anyway.

Boot memory is exactly two documents: Asimov's Three Laws (enforced as a hard-veto filter on every candidate step) and a copy of How to Beat Minecraft. The guide says "reach THE END; you do not know where it is." No coordinates. No direction. Goal discovery is purely sensory.

Honest hearing, not cheating

The portal emits a hum within a radius. The agent only measures loudness — never position. It logs per-tile warmth memories, sweeps the earshot ring systematically, re-swarms the warmest remembered tile when the hum fades, and only locks on once its sensors actually see the portal: purple glow = THE END.

Deaths reset it

When an agent starves or degrades to hp 0, the world regenerates and a fresh generation boots. Wins also respawn. Live counters track wins, deaths, and generation number.

Run it

python3 villager.py                     # popup visualization
python3 villager.py --headless --seed 7 # batch stats, no window
